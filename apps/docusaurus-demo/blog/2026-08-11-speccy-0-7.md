# Speccy 0.7

Speccy 0.7 makes generated references feel like native pages in a Docusaurus site.

<!-- truncate -->

Generated reference routes now use the Docusaurus layout and set route-specific metadata. Navigation, page chrome, titles, and descriptions stay consistent with the rest of the documentation site, including sites that publish more than one static API reference.

The following patch releases added Node.js 22 support and improved scanning and interaction with deprecated-operation labels, request media type alternatives, and schema rows that open when clicked.
