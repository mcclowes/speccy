# Speccy 0.5

Speccy 0.5 adds a read-only mode for API references that shouldn't make live requests.

<!-- truncate -->

Set `tryIt: false` in the renderer or Docusaurus plugin configuration to hide the interactive request builder. The rest of the reference stays intact, including request examples, schemas, and response documentation.

The release also tightens the reference UI with clearer request body headings, consistent sidebar subgroup labels, better-matched code controls, and a smaller optional parameter picker.
