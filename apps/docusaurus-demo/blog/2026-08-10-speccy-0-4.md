# Speccy 0.4

Speccy 0.4 redesigns operation pages around the details readers need while building an integration.

<!-- truncate -->

## What's new

- Schema explorers now cover parameters and response headers.
- Request examples are more focused, with collapsible code blocks for longer samples.
- Response content is easier to scan and compare.
- Optional parameter controls ship with their component styles.
- Docusaurus references can inherit the host site's color mode, typography, and base font size.

This release also aligns the package suite on one version, so `speccy-core`, `speccy-renderer`, `speccy-spectral`, `speccy-cli`, and `docusaurus-plugin-speccy` can be upgraded together.
