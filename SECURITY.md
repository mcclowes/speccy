# Security policy

## Supported versions

Security fixes target the latest released version. Older releases may remain vulnerable and should be upgraded.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/mcclowes/speccy/security/advisories/new) to report a suspected vulnerability. Include the affected package or app, reproduction steps, the likely impact, and any known workaround.

Don't open a public issue or pull request until the report has been assessed. You'll receive an acknowledgment through the advisory, followed by updates as the report is reproduced and a fix is prepared.
